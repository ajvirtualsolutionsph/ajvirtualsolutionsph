What We Built & What It's Made Of

Think of this project like a restaurant — a dining room, a kitchen, and a pantry.

🍽️

The Dining Room

Frontend — what you see & click

  • React + Vite — builds the screens and makes them feel fast
  • TailwindCSS — colors, spacing, and styling
  • React Router — controls which page shows on each click
  • Lucide — icons throughout the app
🍳

The Kitchen

Backend — runs behind the scenes

  • Node.js + Express — the server; takes requests and sends answers back
  • Zod — validates incoming data before acting on it
  • Helmet + Rate Limiter — security guards that block bad actors
🧺

The Pantry

Database & Auth — where data lives

  • Supabase — hosted database that also handles login & passwords
  • RLS (Row-Level Security) — each user sees only their own data, enforced at the database level
