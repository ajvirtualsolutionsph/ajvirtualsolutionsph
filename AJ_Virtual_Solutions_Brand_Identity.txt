ElementSizeWeightUse CaseHero Headline (H1)48–64 px700 BoldSpace Grotesk — main titles ("Hi, I'm AJ")Section Heading (H2)32–40 px700 BoldSpace Grotesk — section titlesSubheading (H3)20–24 px600 SemiboldSpace Grotesk — card titles, project namesBody Large18 px400 RegularInter — lead paragraphs, key descriptionsBody16 px400 RegularInter — standard paragraph textSmall / Caption13–14 px400 RegularInter — helper text, captions, footnotesButton / CTA16 px600 SemiboldInter — buttons, navigation linksNumbers / Codevaries500 MediumJetBrains Mono — pricing, stats, code snippetsText Style Rules
• Use Space Grotesk for ALL headings (H1–H3) — never use it for body copy, it gets fatigueing at small sizes
• Use Inter for body, navigation, buttons, forms, and any UI element under 18px
• Headings use tight line-height (1.1–1.2) for impact
• Body text uses comfortable line-height (1.5–1.6) for readability
• Letter spacing: -0.02em on large headings (Space Grotesk); normal on body (Inter)
• Limit line length to 65–75 characters for body copy
• Use sentence case for buttons and short labels; title case for navigation
• Pricing and stats can optionally use JetBrains Mono for technical credibility ("$2,000" / "95%")

6. Voice & Tone
Brand Voice
Overall VoiceConfident · Practical · Direct · WarmWe areClear, results-focused, transparent about pricing and timelinesWe are notSalesy, jargon-heavy, vague, overly formalTone Examples (from the live site)
• Hero: "Hi, I'm AJ" — first-person, friendly, direct
• Mission: "Helping businesses run smarter" — outcome-focused
• Pricing: "Pay once. Run forever." — short, punchy, memorable
• Urgency: "Only 3 client slots open this month" — honest scarcity
• FAQ: Answers questions in plain English, no fluff
Writing Guidelines
• Lead with the benefit, not the feature
• Use specific numbers ("95% cheaper", "2–4 weeks", "$2,000–$2,500") instead of vague claims
• Write in second person ("you", "your team") to feel personal
• Keep sentences under 20 words when possible
• Use em-dashes — sparingly — for emphasis or asides
